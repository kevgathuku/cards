# Gemini Workflow

This document provides a basic workflow for getting started with the repository.

## 1. Initial Setup

This command will install all dependencies, set up the database, and build the necessary assets.

```bash
mix setup
```

## 2. Running the Development Server

To start the Phoenix server, run:

```bash
mix phx.server
```

You can now visit [`localhost:4000`](http://localhost:4000) from your browser.

## 3. Running Tests

To run the test suite, use the following command:

```bash
mix test
```
